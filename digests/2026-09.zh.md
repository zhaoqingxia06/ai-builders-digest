## 🎙 PODCASTS

### No Priors：Coinbase's Everything Exchange: Agentic Finance, Stablecoins, and Tokenization with CEO Brian Armstrong（2026-09-10）

**一句话要点**：当 AI agent 开始自己花钱，传统支付手续费（每笔固定 30¢ 起）就是天花板，而 **stablecoin** 加**自托管钱包**是现成的低费率全球结算层，Coinbase 正在全押这件事。

Brian Armstrong 是 Coinbase 联合创始人兼 CEO，同时联合创办了抗衰老公司 New Limit。他的核心论据是：agent 电商交易中约 76% 金额低于 30¢，而刷卡通道每笔固定收费就要 30¢，传统金融 rails 根本跑不通；stablecoin 则能在 1 秒内、以低于 1¢ 的成本把钱汇到全球任何角落。为此 Coinbase 做到一条命令就能给 agent 开**自托管金融账户**（无需 **KYC**，因为 agent 没有政府身份证），并把孵化出的 agent 支付协议 **X402** 捐给了 Linux Foundation，Google、Cloudflare、AWS 都在参与。他说「我们不想让 AI 成为没有银行账户的群体」（"We don't want the AIs to be unbanked"），并预计不远的将来 agent 数量会超过人类，agent 经济的体量最终也会超过人类经济。

内部工程侧，Coinbase 给每个团队、每个代码仓库甚至每个人挂一个**「大脑」**：沉淀全部事故记录、财务控制规则、AB 测试和 PR 历史；agent 改代码被人类纠正后，纠正内容必须回写大脑，让一次性通过的 PR 比例持续上升，形成他所说的 **recursive self improvement**。他本人现在用内部 harness「**Toshi**」把功能计划拆成阶段，一次拉起 10 个并行 agent（多选便宜模型）执行，几分钟后收到完成通知，CEO 重新开始亲自 ship 功能了。

几个具体数字：Coinbase 88% 的收入已来自非 Bitcoin 交易；上线数月的 **prediction markets** 已达 1 亿美元年化收入；**代币化股票**（真实证券 1:1 托管、先在美国以外开放）瞄准全球约 40 亿没有券商账户的人。New Limit 的**表观遗传重编程**已在人源化小鼠中成功重编程至少一种人体细胞，明年启动首个 phase one 临床试验，首发适应症是酒精性肝病。
