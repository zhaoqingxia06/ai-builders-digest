## 🧭 今日洞察
**核心洞察**：今天的主线是 agent 从"对话框"走进"真实环境"。OpenAI 用 **Dots** 把 AI 变成 24/7 常驻的个人代理，Anthropic 让 **Claude in Chrome** 直接操作用户的浏览器和登录态，两者都在把"每一步都要批准"改成"自主执行加安全分类器兜底"。与此同时，基础设施侧的量级也在跳：**AI SDK** 达到 3000 万周下载，说明 agent 应用的开发底座已经进入主流。

**TOP 3 热点话题**
1. **OpenAI Dots 发布** — Sam Altman 宣布 Dots 到来，Thibault Sottiaux 透露几天内会有数百万个 dot 上线，并预告未来可以创建一整支 dot 团队。
2. **Claude in Chrome 正式可用** — Anthropic 博客宣布该功能登陆所有付费 Claude 套餐，Claude 可自主执行浏览器操作，靠安全分类器拦截 prompt injection。
3. **AI SDK 3000 万周下载** — Guillermo Rauch 公布这一里程碑，并用 Rust 加 GPU 渲染的方式一条视频讲完。

**Claude in Chrome 正式可用**（Claude Blog）
Claude in Chrome 现已在所有付费 Claude 计划中正式可用，Claude 可以在浏览器中自主执行操作，不再需要为每一步都请求批准。执行前会有安全分类器验证每个动作是否安全且符合你的请求。许多日常工具已接入 Claude，但内部仪表盘、遗留系统和供应商门户没有，Claude in Chrome 让 Claude 能够访问这些，它可以查看你所在的页面，并执行读取和输入文本、点击链接、页面间导航、填写表单等操作，沿用你现有的登录状态。Anthropic 去年以试点形式发布该功能，以便在测试的同时加固对 prompt injection 的防御，即隐藏在网站、邮件或文档中试图诱导 AI agent 违背用户意愿行事的恶意指令。这些防御措施让他们有信心将其正式发布。在 prompt injection 攻击中，恶意行为者把指令藏在网页、邮件或表单字段等内容里，你可能永远看不到，但这些指令可以重定向 agent 去做你从未要求的事，例如你让 Claude 起草邮件回复，某封邮件里的隐藏指令却告诉 Claude 把你的其他邮件转发给攻击者。自试点以来，他们改进了模型和 probes 的训练方式，并新增了一组分类器，使 Claude 能够在 Chrome 中安全地采取更多自主行动。评估结果显示这些防护有效，Claude 能识别更多攻击，训练数据来自内部自动化攻击者、外部红队和真实世界监控构成的不断增长的 prompt injection 攻击库，当新攻击成功攻破当前模型时就会被加入库中，用于后续训练。

**Claude in Chrome is generally available**（Claude Blog）
Claude in Chrome 现已在所有付费 Claude 计划中全面可用。Claude 现在可以在浏览器中自主执行操作，不再需要为每一步都请求批准，每次动作前会由安全分类器验证其是否安全并符合用户请求。文章指出，许多日常工具已接入 Claude，但内部仪表盘、遗留系统和供应商门户等还没有，Claude in Chrome 正是让 Claude 触达这些场景：它能查看你所在的页面，并执行读取和输入文本、点击链接、页面间导航、填写表单等操作，且沿用你现有的登录状态。该功能去年以试点形式发布，用于在测试的同时加固对 **prompt injection** 的防御，即隐藏在网站、邮件或文档中、试图诱骗 AI agent 违背用户意愿行事的恶意指令。Anthropic 表示，此后改进了模型和探针的训练方式，并新增了一组分类器，使 Claude 能在 Chrome 中安全地采取更多自主行动。评估结果显示这些防护有效，Claude 能识别更多攻击：团队用不断增长的 prompt injection 攻击库训练 Claude，来源包括内部自动化攻击者、外部红队和真实世界监控，一旦新攻击对当前模型奏效，就会被加入库中用于后续训练。
