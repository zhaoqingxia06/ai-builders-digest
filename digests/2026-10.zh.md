## 🧭 今日洞察
**核心洞察**：今天的主线是 agent 从"对话框"走进"真实环境"。OpenAI 用 **Dots** 把 AI 变成 24/7 常驻的个人代理，Anthropic 让 **Claude in Chrome** 直接操作用户的浏览器和登录态，两者都在把"每一步都要批准"改成"自主执行加安全分类器兜底"。与此同时，基础设施侧的量级也在跳：**AI SDK** 达到 3000 万周下载，说明 agent 应用的开发底座已经进入主流。

**TOP 3 热点话题**
1. **OpenAI Dots 发布** — Sam Altman 宣布 Dots 到来，Thibault Sottiaux 透露几天内会有数百万个 dot 上线，并预告未来可以创建一整支 dot 团队。
2. **Claude in Chrome 正式可用** — Anthropic 博客宣布该功能登陆所有付费 Claude 套餐，Claude 可自主执行浏览器操作，靠安全分类器拦截 prompt injection。
3. **AI SDK 3000 万周下载** — Guillermo Rauch 公布这一里程碑，并用 Rust 加 GPU 渲染的方式一条视频讲完。

## 🧭 今日洞察
**核心洞察**：今天的主题是 agent 从“对话”走向“替你做事”。OpenAI 的 **Dots** 正式登场并强调会自主学习用户偏好、独立承担任务，Anthropic 则把 **Claude in Chrome** 推向正式可用，允许其在浏览器里自主执行操作。与此同时，围绕 agent 的基础设施和评测标准也在快速成形，**AI SDK** 周下载量冲到 3000 万，说明开发者侧的采用已经进入规模阶段。

**TOP 3 热点话题**
1. **OpenAI Dots 发布** — Sam Altman 宣布 Dots 上线，Thibault Sottiaux 补充说几天内会有数百万个 dots 在线，并预告未来可创建一整支 dot 团队。
2. **Claude in Chrome 正式可用** — Anthropic 博客宣布该功能登陆所有付费 Claude 套餐，并允许 Claude 在浏览器中自主执行操作，用安全分类器逐条校验动作。
3. **AI SDK 突破 3000 万周下载** — Guillermo Rauch 公布这一里程碑，并用 fframes 加 Rust 渲染的 GPU 视频展示 5M 到 30M 的增长轨迹。

## 𝕏 / TWITTER
**Sam Altman** 连发三条为 OpenAI 新动作造势：宣布 **Dots** 上线，称这是一种 24/7 为你工作的新 AI 用法，能把你更多时间和注意力还给更高层次的工作；同时力推 **Ultrafast**，直言“太快了，我再也不想回去”；还介绍了 **6.1 Sol**，价格只有 **Astra** 的五分之一，缓存读取折扣高达 95%。

**Thibault Sottiaux** 围绕 **Dots** 展开说明，表示几天内就会有数百万个 dots 在线，覆盖一个庞大而多元的社区。他提到自己在使用两三天后就感到明显跃升，因为 dot 学习用户偏好非常快，还能独立接下相当有野心的任务，团队正从用户如何使用主 dot 中学习，之后再放开创建整支 dot 团队的能力。他还回顾了 DevDay 现场的氛围。

**Thariq** 分享了 Anthropic 关于如何让 **Claude** 更快的博客内容，并抛出一句颇有传播度的提示词心得：试着告诉 Claude“我们有能力做任何事，请更勇敢一点”，然后反问读者有没有对自己说过同样的话。

**Guillermo Rauch** 公布 **AI SDK** 已达到 3000 万周下载量，并用 **fframes** 加 opus 一次性做出里程碑视频，强调视频用 Rust 编写、在 GPU 上渲染。他还发了一张图，展示产品缺陷与下载量之间的负相关，并留下一句“你直接发布就行了”。

**Aaron Levie** 认为 AI 行业完全有可能在可预见的未来通过一套共享的标准与实践来处理安全与安保问题。他指出能力进步到某个阶段必然带来更强的监督、测试以及责任与监管层级，但当下行业仍能集体对齐这些努力，这次能这么快成形且不削弱竞争，指向 AI 更光明的未来。

**Nikunj Kothari** 抛出两条关于当下市场的坦率观察。第一关于人：如今找到“传教士”比以往更难，联合创始人离开自己创办的公司去加入“显而易见的赢家”，上市公司 CEO 跳去实验室，公司被 Windsurf 式拆分，只有被选中的人能进入未来公司。第二关于护城河：护城河不再是单一的东西，在应用层，harness 是上千件小事做好的总和，很多还是不可见的，最终往往回到“真正的护城河是创始人”，而创始人的护城河是执行速度和适应市场的能力。他还提到 B2B 创始人可以把 X 上的热门内容搬到 LinkedIn，因为 LinkedIn 通常落后一两周。
