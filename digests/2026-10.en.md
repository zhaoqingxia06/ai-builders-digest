## 📰 OFFICIAL BLOGS

**Claude in Chrome is generally available** on every paid Claude plan. Claude can now take actions autonomously in the browser instead of needing approval for every one, with a safety classifier validating each action before it is performed. This matters because many tools people use daily, such as internal dashboards, legacy systems, and vendor portals, do not connect to Claude, and Claude in Chrome lets it access those by viewing the page and taking actions like reading and typing text, clicking links, navigating between pages, and filling out forms using existing logins. Anthropic first announced the pilot last year to test it while shoring up defenses against prompt injection, where malicious instructions hidden in websites, emails, or documents try to trick an agent into acting against the user's wishes. Since then the team improved how it trains both the model and its probes, and added classifiers that make it possible for Claude to safely take more autonomous actions. Claude now recognizes more attacks, trained against a growing library of prompt injection attacks sourced from internal automated attackers, external red-teamers, and real-world monitoring, where a new successful attack is added to the library to inform training.
